Privacy Policy

Draft for review · Effective date not set

This draft explains the current intended data flow for the IntentFlow research demo. It must be checked against the final hosting provider, deployment settings, and any monitoring or analytics added before launch.

1. Text you submit

When you submit a message, the web application sends that text to the configured IntentFlow prediction API to generate a classification. The current API code performs inference in memory and does not intentionally save submitted messages to an application-managed database.

2. Hosting and operational logs

The hosting providers used for the frontend and API may process technical information or retain operational logs according to their own settings and policies. The final providers, log contents, retention periods, and access controls have not yet been confirmed and must be documented before public launch.

3. Sensitive information

Please do not enter passwords, account numbers, payment-card details, identity documents, or other sensitive personal or financial information. IntentFlow is a research demonstration and is not designed to process real customer banking records.

4. Cookies, analytics, and third-party services

The current frontend does not intentionally add analytics or advertising scripts. This must be rechecked after deployment. The frontend contacts the configured prediction API, and the browser and hosting infrastructure may make routine technical requests.

5. Data requests and contact

A contact address, data-request process, applicable jurisdiction, and final retention policy have not been supplied. Add and verify these details before this page is published as a final policy.

6. Changes to this draft

Update this page whenever the data flow, model host, logging settings, analytics, or data-retention practices change. The effective date should be set only after review and approval.

Draft status: This page is not a final privacy notice. Confirm the deployment providers, their logs and retention settings, applicable legal requirements, and a real contact method before public launch.
